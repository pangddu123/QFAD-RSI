# 用临床事件索引导航原文的记忆强化学习

目标是训练 Qwen3.8-27B 把连续医患对话写成通向原文的临床事件索引。Writer 在对话进入系统时抽取事实、关联事件并保存原文位置；Reader 通过 QFAD 图定位并联合读取原始对话，查询结果为抽取策略提供训练反馈。事实图用于导航，最终证据来自原文；回答器固定。

发布文件各有 101 段主会话、100 段亲属问诊和 100 段常识会话；最终检查点仅覆盖上述实际可见部分。原始标注中，患者 1、2 分别有 20、13 次来源 session ID 无法对应主患者会话，包括 0、999、日期形整数及超出范围的编号。它们涉及 16、12 道题。这是来源定位字段不可靠的证据，不能据此断言原文不存在或发生了未来信息泄漏。有效主会话 ID 中没有发现晚于题目检查点的来源。

由此决定：

1. 亲属患病和用药不能并入主患者；常识与具体患者经历分开存放。这属于实体抽取、主体识别和指代消解的基础质量，单列控制，不作为医学强化的核心贡献。
2. 不把整份 source_key_points 当作唯一必需证据集合。先根据原文定位真正相关的断言，再确认完成问题需要哪些事件及关系。
3. 状态更新必须保留历史；“现在的状态”是事件图上的查询结果。
4. 训练问题覆盖六类，保留已答对问题作为记忆保留检验；不能只按失败时间题构建训练池。

统计原始记录见 [dataset_profile.json](dataset_profile.json)。这些统计没有使用患者 3、4 的内容来设计新方法。

逐题阅读 20 道状态更新题后，按提问目标人工归类：9 道测量变化、5 道行为/偏好变化、4 道症状/主观体验变化、2 道用药变化。分类与题目全文保存在统计文件中。停药只是验证例子；训练若只覆盖药物状态，会忽略本数据的大部分状态记忆需求。尤其需要将同名测量的多个时点、生活行为的变化及短暂改善与持续改善组织成可回读的来源序列。

## 医学特点如何改变导航目标

主体识别、否定和时间不是医学独有的属性。这里需要研究的是它们在诊疗中的组合如何决定一组证据是否可用于当前问题。

| 特点 | 前两患者中的实际任务 | 对形成记忆和奖励的影响 |
|---|---|---|
| 事实有不同的有效期 | 用药状态变化、UACR 多次复查、既往药物过敏 | 药物状态沿实际执行事件更新；测量是某时刻的观察；过敏史不能因很久未提及而失去导航入口。不能统一采用最新一句或统一时间衰减 |
| 诊疗是干预与反应的过程 | 患者 2 加量后早饱；患者 1 规律服药但餐后不适和血糖升高 | 需要同时导航到干预前状态、实际治疗、随后反应及相关背景；提到同一药名不足以构成证据包。先后关系本身不等于因果 |
| 医嘱和执行是不同事件 | 患者 1 被要求停恩格列净，随后确认已停；也有偶尔漏打胰岛素的报告 | 抽取分别建立建议、执行、依从性的索引，让 Reader 能查到实际发生了什么 |
| 测量解释依赖条件与趋势 | 患者 2 午夜血糖高而晨起空腹值较低；患者 1 不同时期 HbA1c/UACR 的变化 | 指标、采样条件、时间窗口及数值出处须共同可达；只有同名指标或最新一次数值不足够 |
| 临床证据存在不同强度 | 患者 2 不确定电解质具体数值，且报告无明显夜尿增加、无明显头晕 | “没测/不记得”“明确否认”“有观察但原因不明”不能互换。重要的反面证据也要纳入证据包，不能只找支持预设结论的片段 |
| 当前问题隐含长期约束 | 前期过敏史、既往用药风险提醒、针头恐惧影响后续治疗执行 | 查询不必出现“过敏/恐惧”等词，仍应能沿药物、治疗和个人限制的关联找到原文。奖励检验相关约束是否被召回，而非总把整个档案塞入上下文 |

这些是待验证的导航目标。训练标注只确认原文记录了哪些患者事实和明确断言；不将合成对话中的医学解释自动当作临床定论。

## 记忆形成

每次输入一个按原有固定边界组织的对话块及已有索引。当前实现提供最多八条最近的可见旧事实，排除正在重新抽取的来源；关联旧索引的选择策略仍需验证。Writer 输出该块值得建立导航入口的事实、事件及关联，不限定为一条修改。其输入只有消息、说话者、系统实际可见的主体提示和记录日期；不输入 benchmark 答案、source_key_points、生成数据时的 event 描述或问题文本。

索引记录包括：事实摘要、相关实体、事件类别、足以区别事件的时间/状态限定，以及 source_id、原文行号和对应原文跨度。数值、剂量、单位与完整解释可以留在原文，只有影响定位或区分的部分必须进入导航表示。摘要不能与原文矛盾。实体身份按患者与亲属分开；关系谓词允许开放表达。来源由环境提供的文档标识和模型选择的消息跨度共同确定。

图分为三层：

- **来源层**：原始消息、角色、可见时间及所属会话。
- **事件索引层**：病史、症状、检查、实际用药、建议和患者约束的导航事实，带区分事件所需的限定条件和出处。
- **关联层**：相同事件的重复报告、有依据的先后与状态变化、明确表达的冲突，以及事件到来源的链接。

重复报告可以合并来源；不同时间的测量、停药和恢复用药保留为不同事件。仅因实体相同不能合并。医生提出的风险或解释按医生断言保存，不自动升级为患者已发生的事实，也不把模型推导的临床结论写入患者病史。

具体例子来自患者 1 主会话 6：最初患者报告自己已持续服用恩格列净约八个月，同时转述医生要求停药；随后患者明确说自己这两天已经停药。图中的既往服用、停药建议、实际停药入口分别指向相关原文。Reader 回读后获得剂量、持续时间和停药后的症状。记录日期为 2024-01-15，但“这两天”的事件时间仍保留原文精度，不伪造精确日期。

Reader 路径为：查询 → QFAD 实体/事件入口 → 相关事件和时间关系 → 原文窗口 → 固定回答器。原文窗口保留必要上下文，不能只截出一个药名。额外原文搜索可以作为受预算约束的 Reader 动作，单列其成本和使用比例；不能用无限制全文输入掩盖导航质量。

## 强化信号

SAGE 的检索召回与精度针对检索证据，不是三元组抽取准确率。本项目保留其 Reader-aware 训练结构，将医疗证据的匹配条件具体化。

对训练问题 q，在当时可见原文中核验可接受的最小证据包集合 E_q。每个证据包说明要读取的患者事实及必要的时间、治疗状态或约束关系，例如“治疗前测量 + 实际加量 + 加量后的食欲变化”。允许多组等价原文。source_key_points 只帮助定位，不能直接作为未经验证的真值。不能定位证据的问题保留在最终 QA 评估中，但暂不产生 Writer 的证据覆盖奖励。

冻结 Reader 后，分别记录：

- G 中是否有通向所需原文的正确事件入口和关系：用于诊断漏抽和错误整合。
- Reader 导航后交付的原文是否覆盖它们：用于诊断检索遗漏。
- 固定回答器是否据此正确回答：用于诊断推理失败。

覆盖在**实际交付的原文**上计算，索引事实无需重写所有证据内容。一个入口能带回多个必要事实时，可以覆盖多个单元。没有关系也能完成的实体题，证据包可以只有一个事实。匹配必须满足问题要求的时间和状态；检出同一药物的旧记录，不能自动算作召回当前用药证据。

首版采用有序目标，避免把若干任意权重叠成一个不可解释的分数。对同一个写入前状态，采样候选抽取集合 z_i，令：

\[
S_q(z_i)=\mathbf 1[\text{答案正确且导航交付的原文满足完整的临床证据要求}],
\]

\[
C_q(z_i)=\max_{E\in\mathcal E_q}
\frac{\text{交付原文中正确覆盖的必要事实及关系条件数}}{|E|}.
\]

在固定训练查询集 Q 上：

\[
R_i^{\mathrm{task}}=
\sum_{q\in Q}S_q(z_i)+\frac12\operatorname{mean}_{q\in Q}C_q(z_i).
\]

这里的 1/2 仅保证覆盖项不能抵消一整道有证据支持的正确回答损失，是优先级编码；不是拟合出来的“医学重要性权重”。全部最终回答得分相同时，证据覆盖仍提供稠密区分。空输出若缺少必要记忆，不能因格式合法或没有幻觉获得高奖励。每组查询固定，跨候选不能删掉困难题。成本先使用相同的写入、存储与读取预算约束，不通过额外自由权重奖励少写。

来源核验逐条决定事实与关系是否写入。通过核验的事实保留；关系须自身有来源支持，且两个端点均可用。错误关系不影响正确端点，不支持的事实只影响自身及依赖它的边。原始抽取输出与逐条判定均保留，准入过程不改写模型生成的断言。细节保留在原文而没有重复写入摘要，不算错误。任务奖励在准入后的图上计算，不因一条局部错误给整批输出相同负分。

来源误差逐条记录，并以未准入事实和关系占全部提议条目的比例 E_i 聚合。首版完整奖励为 R_i = R_i^{task} - 0.25 E_i。没有提议时 E_i 为零，无法解析的输出 E_i 为一；没有必要证据的空图不能获得任务成功分。来源错误不会抹去正确部分产生的查询效用。覆盖项与来源项合计处于 [-0.25, 0.5]，因此不能抵消一整道有完整证据支持的正确回答。0.25 是待消融的实验系数，不是医学重要性量纲。

同组候选共享原文、写入前图、问题集和读取预算。完全相同的回答提示复用回答及其评分；完全相同的临床证据评分输入复用一次覆盖判定，避免评分随机性成为候选差异。只有至少两个成功解析的候选在任务效用上存在差异时才更新参数；只有格式或来源错误比例不同的组跳过更新。

更新采用整段抽取输出的组相对优势；逐条来源反馈在候选级聚合，当前没有实现事实 token 级的独立信用分配。训练状态固定使用每组第一个采样结果推进，不选择奖励最高的图。训练状态不是部署结果；部署评价需要用固定策略从原文重新抽取。

这是本项目拟验证的奖励，尚无医学强化学习有效性结论。需要检验的可证伪预测是：能导航到完整病程证据的图优于只找到同名药物的图；错误时间版本、疑似升级为确诊、计划变成执行不能因碰巧答对获得高奖励；重复读同一原文不能增加覆盖分；正确索引但未检索到与已检索到但回答错误应产生不同诊断。

## 学习过程

1. 用同一原文块、同一写入前图采样多个完整抽取输出。逐条准入后建立 QFAD 图，执行相同 Reader 和固定回答器，计算任务奖励并记录来源误差。
2. 采用 SAGE 的组相对策略优化思路更新 Writer 生成 token。训练输入和检索返回文本不作为生成动作计算梯度。组内完全同分时记录无学习信号，不伪造优势。
3. 更新后从原始会话重新抽取并构图，以生成结果评价策略；不把训练时奖励最高的候选图当作部署图。
4. 冻结新图，训练 Qwen27B Reader 的实体入口、关系扩展、来源回查和终止选择。Reader 同样使用有证据支持的回答成功与覆盖信号。Writer 阶段不同时更新 Reader。
5. 在两个角色的固定快照之间交替，分别报告 Writer、Reader 以及联合收益。

Writer 和 Reader 使用同一 Qwen27B 基座，回答器使用固定副本。初始 Writer 实验固定 QFAD 检索；后续 Reader 策略学习是本项目适配，不能声称复现了 SAGE 的 GFM Reader。SAGE 形式化输入含查询，本项目在写入阶段去掉查询，让查询只进入奖励端，以测试面向后续未知问题的记忆形成。

## 最小验证路线

先在前两患者的真实片段上完成三项验证：完整事件抽取可运行；奖励对真实的主体、时间和状态变化案例排序合理；同一个写入前状态中存在可学习的抽取候选差异。随后才更新参数。

正式比较保持 Qwen27B、原文、Reader 和预算相同，比较未训练抽取器、SAGE 通用证据奖励、医学证据包奖励。每个 checkpoint 均从可见原文重新形成记忆，评价全部 197 题及六类分项，同时报告目标时间证据覆盖、跨阶段证据包完整性、长期约束召回、原文读取量及总成本。主体混淆和实体抽取质量单列控制。旧的查询触发图修补作为独立对照，不替代完整抽取基线。

患者 1、2 可以反复迭代，称为训练环境内的改善。患者 3、4 保留为冻结迁移评估；已有旧模型迁移作业继续完成，不使用它们的错误反过来制定本版奖励。

## 限制

SAGE 官方代码链接本次不可访问，部分奖励权重和多轮反馈协议不能从代码确认；本方案使用论文框架，不宣称官方训练复现。医学证据链需要额外来源标注和校准，费用计入训练成本。LLM 来源判断存在误差；CMED 与 THYME 的结果只支持相关表示具有研究依据，不能证明这里的评分器可靠。数据是生成的纵向医患对话，训练两位患者的结果不能代表临床有效性。
